# Humour

DRAFT — the sister site's humour guide was written around a plumber persona and has been dropped. Nothing in the current copy is jokey, so this file only records the default until the owner says otherwise.

## Default

Dry and plain. A light aside is fine once per post if it comes naturally. Never a forced pun, never a joke at the reader's expense (their gutter is overflowing, not a punchline).

## Rules if humour is added later

- Deadpan beats wink. No exclamation marks, no emojis.
- One moment per 400-500 words at most.
- Punch at the industry or at yourself, never at the homeowner.
- No pop-culture references that date within a year.
- Cut any joke that needs explaining.

Ask the owner what the brand voice should sound like before writing a full humour guide. Don't invent a persona.
